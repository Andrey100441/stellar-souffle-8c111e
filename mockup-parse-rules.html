Площадка

Правила ниже (периоды ЕО, слова, инициатор, тип по умолчанию) действуют для выбранной площадки. Рудник без своих правил использует общие. Какие правила применить к работе, форма решает по руднику машины. ИИ и справочники — общие для всех площадок.

ИИ-разбор общее для всех площадок

Выключено — форма раскладывает текст только по этому словарю, без ИИ. Включено — ИИ получает словарь как обязательные правила; тип работ, причина и инициатор по словарю всегда главнее ответа ИИ.

1. Тип работ

Ежедневное обслуживание (ЕО) — до двух периодов в сутки

Время важнее слов: если работа открыта в периоде ЕО, тип ставится всегда, что бы ни было написано (в тексте могут быть исполнители и детали ремонта). Вне периодов — по словам ниже; порядок строк — приоритет (стрелки меняют порядок).

Категория (тип работ)Слова-триггеры и сокращения (через запятую)

Вне периодов ЕО и без слов из таблицы тип не подставляется — его выберет ИИ по смыслу текста или пользователь.

2. Подсистема и отказ

Отказ можно не выбирать — тогда его выберет ИИ или пользователь. Правило срабатывает, только если такая подсистема есть в шаблоне модели машины.
