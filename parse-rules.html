Площадка

Правила ниже (периоды ЕО, слова, инициатор) действуют для выбранной площадки. Рудник без своих правил использует общие. Какие правила применить к работе, форма решает по руднику машины. ИИ и справочники — общие для всех площадок.

ИИ-разбор общее для всех площадок

Выключено — форма раскладывает текст только по этому словарю, без ИИ. Включено — ИИ получает словарь как обязательные правила; тип работ, причина и инициатор по словарю всегда главнее ответа ИИ.

1. Тип работ

Ежедневное обслуживание (ЕО) — до двух периодов в сутки

Время и слова равноценны: тип ставится по словам ниже (порядок строк — приоритет, стрелки меняют порядок). Если слов типа в тексте нет, а работа открыта в периоде ЕО, — ставится тип периода ЕО. Слово от 8 букв с одной опечаткой тоже засчитывается («перключается» = «переключается»).

слово — слово (или его форма) есть в нескольких строках раздела; наведите, чтобы увидеть где.

Категория (тип работ)Слова-триггеры и сокращения (через запятую)

Вне периодов ЕО и без слов из таблицы тип не подставляется — его выберет ИИ по смыслу текста или пользователь.

2. Отказы подсистем общее для всех площадок

Какие отказы можно выбрать у подсистемы — в форме ввода и в разделе 3. Сохранение добавит отмеченные отказы в шаблоны всех моделей, где есть эта подсистема (аварийные и плановые работы), и уберёт неотмеченные. Исключения по отдельным машинам и записанные работы не меняются.

6. Модели техники

Как пишут модель или марку русскими буквами и сокращениями: «камацу» = KOMATSU. Можно указать марку целиком (KOMATSU — все её модели) или конкретную модель. Форма ввода и ИИ ищут машину по борту среди моделей, названных в тексте.
