Наработка по машинам

TR DR1 DR2

Наработка оборудования вносится ежедневно по каждой машине: TR — наработка двигателя, DR1/DR2 — дополнительные подсистемы (если есть). «Средняя наработка в сутки» — среднесуточная наработка за выбранный период, «Общая наработка» — суммарная наработка за выбранный период. Тренд показывает рост/снижение наработки по датам периода (по месяцам, если фильтр «Месяц» не выбран, иначе по суткам) — наведите на график, чтобы увидеть дату и значение. Кликните «Детали» справа, чтобы увидеть наработку по месяцам для конкретной машины (или сразу по дням, если в фильтрах уже выбран конкретный месяц) — из списка месяцев можно провалиться в наработку по дням.
