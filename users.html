Пригласить пользователя

На указанную почту сразу уходит письмо-приглашение. Пользователь открывает его, нажимает «Принять приглашение» и попадает в систему с выбранной ролью; дальше входит по коду с почты или подключает телефон по QR-коду (почта вверху справа → «Мои устройства»). Регистрации нет — войти может только тот, кого пригласили здесь. Пока приглашение не принято, его можно отправить ещё раз или отозвать.

Стартовая страница

Просмотр — видит данные своей области. Ввод ремонтов — только форма ввода ремонтов для машин своей области, без аналитики. Редактор — ещё может менять технику и плановые показатели своей области. Администратор — весь парк, справочники (цены, шаги ТО, персонал), удаление оборудования и управление пользователями. Объекты — область пользователя: шахты, сгруппированные по объекту (клик — выбрать или снять, можно несколько). Без области пользователь не видит технику. Доступ — какие страницы видит пользователь (клик — выбрать или снять). Пусто — все страницы его уровня доступа. Администратору доступны все страницы, у него поле неактивно. Доступ только сужает уровень: «Пользователи» и «Словарь разбора» остаются у администратора, «Ввод ремонтов» — у редактора и администратора; уровню «Ввод ремонтов» всегда открыта только его форма. Закрытые страницы скрыты в меню, по ссылке открывается стартовая. Стартовая страница — что открывается после входа (по коду с почты, по приглашению, по QR) и при открытии адреса сайта. «По уровню доступа»: «Ввод ремонтов» — форма ремонтов, остальные — «Состояние оборудования». Выбрать можно только страницу из «Доступа». У уровня «Ввод ремонтов» всегда открывается форма ремонтов.
